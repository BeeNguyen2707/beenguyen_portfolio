Concept Rescue Drone

This is a project for my Mechanical Drawing class in Fall 2024.

The task involved designing an octo-rotor drone capable of carrying dual camera systems and four distinct sensors.

Specifically designed for rescue and surveillance, it features both real-time optical and thermal imaging capabilities.

Integrated sensors include dual anti-collision units, an altimeter, GPS, and a humidity sensor specifically tailored for wildfire prediction.

The octo-rotor configuration provides significant lift, allowing for modular camera upgrades and removing the need for traditional landing gear.
